# Signature Work Portfolio

## Overview

This portfolio highlights three projects from my time as a student at the University of St. Thomas. I chose these projects because they show different parts of my growth as a developer: building visual front-end experiences, designing full-stack applications, and thinking carefully about privacy, data ownership, and responsible software tools.

Together, these projects represent a progression from learning the fundamentals of web development to building more complete applications with authentication, databases, validation, and security concerns. They also reflect the St. Thomas emphasis on using technical skill with purpose: not just making software that works, but making software that is understandable, responsible, and useful to real people.

## Solar System Animation

Repository: [solar-system-animation](https://github.com/ctronrud1/solar-system-animation)

Solar System Animation is a static front-end project built with HTML, CSS, JavaScript, and image assets. The project visualizes the solar system with animated orbital paths, planet images, a generated star field, speed controls, pause/resume behavior, and selectable planets with an information panel.

I chose this project because it shows the foundation of my front-end development work. Even though it is smaller than the other projects, it required coordination between structure, styling, animation timing, image placement, and JavaScript interaction. It is a good example of learning how much can be done with core browser technologies before relying on larger frameworks.

## Europe Trip Budget Tracker

Repository: [europe-trip-budget-tracker](https://github.com/ctronrud1/europe-trip-budget-tracker)

Europe Trip Budget Tracker is a full-stack Next.js application for planning and tracking expenses during a long trip. It includes authentication, protected dashboard routes, trip management, budget categories, expense tracking, currency-rate records, analytics, CSV export, Prisma database modeling, and validation utilities.

I chose this project because it represents a more complete software system. It goes beyond page layout and includes real application concerns such as user accounts, authorization boundaries, database schema design, server-side actions, input validation, and safe export handling. This project connects strongly to practical software engineering because it focuses on building something organized, secure, and useful for a real planning problem.

## Snapchat Archive

Repository: [snapchat-archive](https://github.com/ctronrud1/snapchat-archive)

Snapchat Archive is a local-first Node.js project for inspecting and organizing a Snapchat My Data export. It is designed to keep raw export data and generated artifacts private while allowing the code, tests, documentation, and folder structure to be safely stored in source control.

I chose this project because it reflects a different kind of software responsibility: handling personal data carefully. The project emphasizes privacy-aware development, safe `.gitignore` rules, local-only processing, dry-run workflows, and documentation about future automation boundaries. It connects to the St. Thomas mission by treating technology as something that should respect people, their data, and their agency.

## Reflection

These three projects show different stages and dimensions of my development as a computer science student. The solar system animation demonstrates creativity and front-end fundamentals. The budget tracker demonstrates full-stack application design and practical engineering. The Snapchat archive demonstrates careful thinking about privacy, data portability, and responsible tooling.

Across the portfolio, the common thread is learning to make software that is not only functional, but also explainable and maintainable. Each project required me to make decisions about structure, documentation, source control, and the needs of a future user or developer. That combination of technical implementation and thoughtful communication is what I want this portfolio to represent.
