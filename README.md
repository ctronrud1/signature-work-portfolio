# Charlie Tronrud - Senior Capstone Portfolio

## Overview

Welcome to my Senior Capstone Portfolio for CISC 480 at the University of St. Thomas. This portfolio highlights projects I created during my time as a Computer Science student that represent different areas of programming and problem solving that I have enjoyed learning about.

I chose these projects because they each represent different technical skills and interests that I developed throughout college. Together, they show my growth in full-scale application development, front-end interactivity, automation, and creating software with real-world purpose.

---

## Budget Tracker Application

Repository: [europe-trip-budget-tracker](https://github.com/ctronrud1/europe-trip-budget-tracker)

### Why I Chose This Project

I chose to highlight this project because it was the first full-scale application I had built in a couple of years, and I wanted to challenge myself to create something larger and more realistic again.

One of the main reasons behind the project was my interest in traveling. I enjoy going to new places and wanted a better way to organize budgets, expenses, and planning while traveling. I also saw it as an opportunity to build something that could actually be useful in my own life rather than just another class assignment.

Working on this project pushed me to think more deeply about application structure, databases, security, and how different parts of a system connect together. It reminded me how much I enjoy building projects that have a real-world purpose and can continue growing over time.

### Skills Demonstrated
- Full-scale application development  
- Database organization  
- Authentication and security planning  
- System architecture and scalability  
- Problem solving through real-world software design

## Snapchat Media Archiver

Repository: [snapchat-archive](https://github.com/ctronrud1/snapchat-archive)

### Why I Chose This Project

I chose this project because I wanted to preserve years of memories between my friends and me from college. My buddies and I have saved a huge amount of photos and videos inside Snapchat group chats over the years, and I realized there was no easy way to download and organize everything in one place.

The goal of this project was to build a system that could automate downloading, organizing, and preserving saved memories with timestamps and structure so that they could be looked back on later.

While the project started as something personal, it became a good challenge in automation, file organization, browser scripting, and managing large amounts of media in a structured way.

### Skills Demonstrated
- Browser automation  
- File organization systems  
- Data processing  
- Workflow automation  
- Structured media management
